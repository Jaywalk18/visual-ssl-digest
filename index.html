  • 今日最值得看GPUA 和 KODA。前者把 vision-only foundation model 的几何结构无监督映射到 VLM 语义空间，后者用 kernel discrepancy 找 CLIP/SigLIP 等表征之间真正不同的样本子结构。
  • 建议精读顺序GPUA -> KODA -> The Loss Is Not Enough -> BabyCL；随后读 RePercENT 与 ChannelTok；Stateful Visual Encoder、FINO、IN2R、VideoCUPS 按项目需要精读。
