  • 今日最值得看LeVLJEPA、MEPA、Information-Regularized Attention、SpiralFovea。四篇分别对应非对比图文 JEPA、视觉 AR 表征对齐、VLM 视觉信息注入正则、自适应视觉 tokenization。
  • 建议精读顺序先读 LeVLJEPA -> MEPA -> IRA -> SpiralFovea；随后读 Cross4D-JEPA / MoVA / HyFL-CLIP / CPF-GCD / Active Spatial Guidance / Rosetta；P2/P3 只扫 invariance、视频时间相关、数据蒸馏和 tokenizer 诊断。
  • 新增/更新/过滤数量arXiv 官方 7 个 new 页面推进到 Thursday, 2 July 2026：992 raw listing entries，跨分类去重 702 个 arXiv ID；其中 new/cross 唯一 ID 436，replacement-only 266；今日入选 15 篇，replacement/status 变化 6 条，过滤/降级记录 24 条。
  • 主要判断今天最强主线是“视觉 token 怎么被训练目标和下游生成/语言接口塑形”：LeVLJEPA、MEPA、SpiralFovea、Active Spatial Guidance 都在改视觉 token 的学习或输入方式。医学、3D、机器人、时序和 graph 噪声很多，需要严格降级。
