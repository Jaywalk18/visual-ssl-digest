核心问题

视频预训练和视频 MLLM 都受 token budget 限制，predictive visual code 是一个值得借鉴的自监督压缩信号。

方法拆解

只在条件预测成本高时发送完整 reference frame，否则把帧间变化、运动和 residual 编成紧凑 P-tokens。

主要贡献

把视频 MLLM 的视觉输入从独立帧编码改成预测式视觉码，显式利用时序冗余。

实验看点

摘要称在 11 个 benchmark 上相对 Qwen3 系视频模型有提升，并减少视觉 token 重复。

局限与读法

更偏接口/推理效率，未必产生更好的通用视觉 encoder；预测成本阈值和场景切换鲁棒性需要看正文。
