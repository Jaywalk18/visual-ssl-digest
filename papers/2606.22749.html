核心问题

通用视觉表征如果不能高分辨率输出，就很难服务分割、检测、几何等任务；这篇补齐 VFM 到 dense task 的接口。

方法拆解

把低分辨率 VFM patch/pool features 提升到 geometry-aware ray domain，用 direction-aware guidance、any-resolution cross-attention、RayPE 和 neighborhood attention 重建任意分辨率 feature maps。

主要贡献

面向 DINO/CLIP/SAM 类 VFM 的通用特征上采样，目标是在 dense prediction 中保留语义 fidelity 和几何一致性。

实验看点

摘要称跨多种 dense prediction tasks 达到 SOTA，参数量约为 AnyUp 的 16%，推理约快 7x。

局限与读法

它是 feature post-processing/upsampling，不是新预训练目标；效果可能依赖下游 dense task 和基座 VFM。
