核心问题

最近 RAE/DiT/visual tokenizer 正在把自监督视觉 encoder 的 feature 变成生成模型 latent，IDEAL 直接处理这个桥接层。

方法拆解

构建离散 representation autoencoder，并让量化 tokens 同时对齐浅层 VFM features 与深层 VFM features：浅层补足局部外观/结构细节，深层保持语义抽象。

主要贡献

指出现有 RAE 依赖深层 VFM 表征时容易丢细粒度视觉信息，离散化后尤其难恢复；IDEAL 用 in-depth alignment 修复这个 token latent 的信息瓶颈。

实验看点

摘要显示方法面向 semantically rich latent spaces for image generation，并强调浅层/深层 feature 互补；代码已公开，便于复现 tokenizer/RAE 细节。

局限与读法

主要证据仍围绕 image generation latent quality；作为通用视觉表征是否提升分类、检索、dense prediction 或 VLM encoder 需要进一步验证。
