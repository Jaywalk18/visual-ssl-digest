先说结论。VLM 预训练越来越受视觉 token 冗余和 projector/LLM 接口限制；这篇提供了一个读视觉 token 表征生命周期的视角。 挑战“视觉 token 必须贯穿所有 LLM 层”的对称架构假设，认为感知保真与语言深层推理可以异步演化。

核心问题

VLM 预训练越来越受视觉 token 冗余和 projector/LLM 接口限制；这篇提供了一个读视觉 token 表征生命周期的视角。

方法拆解

通过 LLaVA-1.5 layer-wise attention 分析发现 visual saturation；提出 Dual-Path Vision Token Routing，DPVR-LF 在饱和点把视觉 token 路由到一层可训练 side branch，深层主干执行 text-only forward，最后再融合。

主要贡献

挑战“视觉 token 必须贯穿所有 LLM 层”的对称架构假设，认为感知保真与语言深层推理可以异步演化。

实验看点

摘要报告 DPVR-LF 约 3% trainable parameters 下保持竞争性多模态表现，同时减少深层 Transformer 的视觉计算。

局限与读法

主要是 MLLM 推理/架构效率，不是自监督预训练；证据集中在 LLaVA-style 架构，跨模型需验证。
