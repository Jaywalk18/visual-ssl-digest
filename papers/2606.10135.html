先说结论。它和 Next Forcing 共同指向“视频 foundation model + world model distillation/rollout”的新训练栈。 提供一个 open-source interactive video world model 框架，减少 causal pipeline 的阶段数，并支持多种现有视频 backbone。

核心问题

它和 Next Forcing 共同指向“视频 foundation model + world model distillation/rollout”的新训练栈。

方法拆解

从预训练视频 backbone 出发，先注入 camera control，再通过 few-step Distribution Matching Distillation 把 backbone 转成 action/camera-controllable world model；采用 bidirectional autoregressive paradigm 提高长程 rollout 的自校正能力。

主要贡献

提供一个 open-source interactive video world model 框架，减少 causal pipeline 的阶段数，并支持多种现有视频 backbone。

实验看点

摘要称 recipe 可覆盖 Wan2.1、Wan2.2、HunyuanVideo、LTX 等模型，并支持 secondary fine-tuning、history compression 与 4-bit training/inference 选项。

局限与读法

偏工程系统与生成/控制质量，通用视觉表征收益需要通过冻结特征、动作可恢复性、视频理解等下游指标验证。
