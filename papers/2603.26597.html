先说结论。这是今天最贴近“通用视觉自监督”的主线：把现有 DINO/MAE/CLIP 类 image features 稳定迁移到 video representation。 把 image SSL backbone 向 video 表征迁移时的冲突明确建模为 intra-video consistency 与 inter-video separability 的 trade-off，而不是简单加 temporal module 后全量微调。

核心问题

这是今天最贴近“通用视觉自监督”的主线：把现有 DINO/MAE/CLIP 类 image features 稳定迁移到 video representation。

方法拆解

Co-Settle 在冻结 image-pretrained encoder 上加轻量投影层，用 temporal cycle consistency 保持同一对象跨帧稳定，同时用 semantic separability constraint 保持跨视频区分能力。

主要贡献

把 image SSL backbone 向 video 表征迁移时的冲突明确建模为 intra-video consistency 与 inter-video separability 的 trade-off，而不是简单加 temporal module 后全量微调。

实验看点

摘要称在 8 个 image-pretrained models 上验证，支持轻量投影能改善该 trade-off。

局限与读法

依赖已有 image-pretrained encoder；是否能替代大规模 video-native SSL 预训练还需要更大规模视频任务验证。
