先说结论。视觉 token 生成模型越来越像语言模型，但这篇明确说明视觉 token 的 KD 规则不同，是构建轻量视觉基础模型的关键工程与方法信号。 指出语言模型 KD 的若干技巧不能直接迁移到图像，因为视觉 AR 存在更长 decoding horizon 和 token 多义性。

核心问题

视觉 token 生成模型越来越像语言模型，但这篇明确说明视觉 token 的 KD 规则不同，是构建轻量视觉基础模型的关键工程与方法信号。

方法拆解

系统评估视觉 AR 生成中的 KD，并提出 VarKD，在 student samples 上蒸馏，同时选择性使用 teacher supervision 以降低视觉 token ambiguity。

主要贡献

指出语言模型 KD 的若干技巧不能直接迁移到图像，因为视觉 AR 存在更长 decoding horizon 和 token 多义性。

实验看点

摘要称在 ImageNet、多种 AR backbone 上，VarKD 持续优于既有 KD baseline，缩小小模型与大模型差距。

局限与读法

面向图像生成压缩而非判别式视觉 SSL；对 learned representation 的线性/迁移性能影响需要额外评测。
