先说结论。长视频自监督和 VLM 预训练都受 token budget 约束，MemoryCard 是对视频表征组织方式的实用改造。 把长视频 VLM 的证据单位从孤立帧提升到事件级 memory card，减少 answer-relevant evidence 稀疏时的检索碎片化。

核心问题

长视频自监督和 VLM 预训练都受 token budget 约束，MemoryCard 是对视频表征组织方式的实用改造。

方法拆解

先对视频和语音/字幕做 self-reading，将长视频切成主题/事件单元；每个单元生成 event-level gist 并选择代表性视觉时刻，形成可检索 Memory Cards。

主要贡献

把长视频 VLM 的证据单位从孤立帧提升到事件级 memory card，减少 answer-relevant evidence 稀疏时的检索碎片化。

实验看点

摘要称在相近 visual-token budget 下提升 long-video QA，最高相对准确率提升 21.8%。

局限与读法

是 inference/augmentation framework，不是新的 video backbone pretraining；Memory Card 生成质量可能限制泛化。
