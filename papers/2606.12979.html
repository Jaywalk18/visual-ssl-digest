核心问题

如果关注 JEPA world model 的在线适应和 memory modulation，这篇值得快速扫读。

方法拆解

比较 operand-side injection (EI-JEPA) 与 operator-side modulation (EPM-JEPA)：后者用经验表征生成 LoRA low-rank weight deltas，调制 predictor weights。

主要贡献

把 JEPA-family world model 的 adaptation 拆成“改 hidden state”与“改 operator”两类机制，并做 preregistered comparison。

实验看点

摘要报告 Moving MNIST gravity shift 中 EPM-JEPA 与 EI-JEPA 的主比较是 null result，但 EPM-JEPA 相对 no-memory baseline 有 1.90% 次要提升。

局限与读法

实验规模小且结论谨慎；单作者预注册研究更适合作为思路扫读，不宜过度外推。
