先说结论。object-centric video SSL 是最近连续主线，SSync 和 TSA/Dual-State Slot Attention 都在处理 slot 表征的稳定性与可扩展性。 解决 video object-centric learning 中 encoder attention map 与 decoder object map 属性不同、密集对齐易传播噪声且二次复杂度高的问题。

核心问题

object-centric video SSL 是最近连续主线，SSync 和 TSA/Dual-State Slot Attention 都在处理 slot 表征的稳定性与可扩展性。

方法拆解

SSync 不做全 spatio-temporal patch 的密集对齐，而是选择性蒸馏 encoder 的边界 refinement 和 decoder 的 interior denoising；再用 transitive pseudo-label merging 合并重叠 slots。

主要贡献

解决 video object-centric learning 中 encoder attention map 与 decoder object map 属性不同、密集对齐易传播噪声且二次复杂度高的问题。

实验看点

摘要称可作为 plug-and-play 模块提升 decomposition quality，对 slot configuration 有鲁棒性，并把对齐复杂度降为线性。

局限与读法

仍需看 benchmark 是否覆盖真实开放视频；slot redundancy 与 pseudo-label 合并可能依赖阈值和场景复杂度。
