先说结论。MAE/VQ/RAE/AR 图像模型都依赖视觉 token 设计，ChannelTok 的“通道即 token”可能影响后续通用视觉预训练的 token budget 策略。 提出轻量 CNN-Transformer hybrid tokenizer，在视觉 token 预算变化时保持质量，并支持 variable-length autoregressive image generation。

核心问题

MAE/VQ/RAE/AR 图像模型都依赖视觉 token 设计，ChannelTok 的“通道即 token”可能影响后续通用视觉预训练的 token budget 策略。

方法拆解

把 latent channel 作为视觉 token，而不是固定空间 token；训练时使用 stochastic tail-dropping，迫使通道按语义重要性自然排序，推理时保留前 k 个通道即可得到可变长压缩。

主要贡献

提出轻量 CNN-Transformer hybrid tokenizer，在视觉 token 预算变化时保持质量，并支持 variable-length autoregressive image generation。

实验看点

摘要称在 ImageNet 上达到新的质量-效率边界，rFID 2.92，同时比现有强 tokenizer 更快、参数更少。

局限与读法

当前主要以图像重建/生成质量衡量；作为通用视觉表征 tokenizer，还需要更多分类、检索、dense prediction 和 VLM 接口实验。
