先说结论。通用视觉表征越来越需要高效 token 选择，跨层演化信号比静态 attention 分数更有迁移价值。 把 token compression 的依据从单层显著性改成跨层动态，为理解视觉 encoder 内部信息流提供了诊断角度。

核心问题

通用视觉表征越来越需要高效 token 选择，跨层演化信号比静态 attention 分数更有迁移价值。

方法拆解

分析视觉 token 在 encoder 层间的 evolution directions，保留持续偏离群体演化方向的信息 token，作为多层演化感知压缩策略。

主要贡献

把 token compression 的依据从单层显著性改成跨层动态，为理解视觉 encoder 内部信息流提供了诊断角度。

实验看点

摘要称在图像/视频理解中提升 LVLM 推理效率并保持性能。

局限与读法

压缩目标仍面向 LVLM inference；是否能反哺预训练 token pruning 或 masked modeling 还需实验。
