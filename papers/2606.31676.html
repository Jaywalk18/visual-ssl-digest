方法拆解

主要贡献

论文显示 corpus-level class statistics 与 image-level attention 对 frozen ViT token reduction 可互补。

实验看点

摘要称 DINOv3 ViT-B/16 sequence 从 201 减到 107，ImageNet Top-1 84.706%，高于 dense baseline 83.514%。

局限与读法

使用 ground-truth class 选择 TF-IDF row，监督假设较强；更像受控分析，不是可直接部署的通用无监督剪枝。
