先说结论。许多强视觉 encoder 在接入 LLM 时会丢视觉结构，这篇有助于判断 alignment 是否破坏原始通用视觉表征。 提出 LS-curse 现象：full-parameter alignment 会扰乱 per-token visual feature linear separability；low-rank alignment 更能保留 modality-specific knowledge。

核心问题

许多强视觉 encoder 在接入 LLM 时会丢视觉结构，这篇有助于判断 alignment 是否破坏原始通用视觉表征。

方法拆解

系统比较 VLM alignment 阶段 full-parameter update 与 low-rank adaptation，分析低秩 alignment 对 visual features 线性可分性、表征稳定性和保守/幻觉行为的影响。

主要贡献

提出 LS-curse 现象：full-parameter alignment 会扰乱 per-token visual feature linear separability；low-rank alignment 更能保留 modality-specific knowledge。

实验看点

摘要称覆盖 100+ alignment configurations、3 类 low-rank operators 以及不同 rank、encoder 设置。

局限与读法

主要是 alignment 阶段分析；结论对不同 LLM/Vision encoder 尺度、数据配比和 instruction tuning 流水线的泛化需验证。
