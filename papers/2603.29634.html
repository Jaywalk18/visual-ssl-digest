先说结论。RAE、VQ、continuous tokenizer 正在重塑图像基础模型的 bottleneck；MacTok 是今天最值得跟的图像 token 压缩表征工作。 把连续 tokenizer 的压缩极限和语义保持放在一起优化，让 64/128 个 tokens 仍能保留可生成和可判别信息。

核心问题

RAE、VQ、continuous tokenizer 正在重塑图像基础模型的 bottleneck；MacTok 是今天最值得跟的图像 token 压缩表征工作。

方法拆解

Masked Augmenting 1D Continuous Tokenizer 通过 random masking、DINO-guided semantic masking、global/local representation alignment 来避免少 token 下的 posterior collapse。

主要贡献

把连续 tokenizer 的压缩极限和语义保持放在一起优化，让 64/128 个 tokens 仍能保留可生成和可判别信息。

实验看点

摘要称 ImageNet 上 256 分辨率 gFID 1.44，512 分辨率配合 SiT-XL gFID 1.52，并最多减少 64 倍 token 用量。

局限与读法

实验重点仍是 image generation；是否提升下游识别、检测、分割或 VLM 输入效率还需额外验证。
