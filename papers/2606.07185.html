核心问题

通用视觉自监督越来越受制于 latent/token 接口；AdaTok 直接处理“视觉表征需要多少 token”这个基础问题。

方法拆解

提出 self-budgeting discrete 1D tokenizer。Prioritized Representation Learning 用 nested tail masking 学会 token 前缀可解码性，并用 Multi-Head LoRA decoder heads 减少不同预算下的语义漂移；Adaptive Token Allocation 用 deterministic-group GRPO policy 在候选预算中选择内容条件 token 数；Dynamic Pareto Weighting 平衡 fidelity 与效率。

主要贡献

把视觉 token 数从固定的训练/部署超参数变成 tokenizer 自己的一次前向输出，使视觉复杂度高的图像获得更多 token，简单图像少用 token。

实验看点

ImageNet-1K 上 AdaTok-Full 在 256 tokens 达到 rFID 1.31；AdaTok-Adaptive 约 118 tokens 平均预算下 rFID 1.50；AR image generation 中 adaptive representation 带来约 2.1x throughput。

局限与读法

实验重心仍是重建和图像生成；是否改善下游识别、dense prediction、VLM 输入或视频 tokenizer 还需要额外验证。GRPO budget policy 也增加了训练复杂度。
