核心问题

TEVI/ViSAE 之后，SAE 正在进入视觉语言表征解释；这篇有助于判断 CLIP image features 与 LLM 输出之间的信息瓶颈。

方法拆解

用 83 个 bistable stimuli 做 3320 次 caption generation 行为基线，再在 LLaVA-1.6-7B 实际读取的 CLIP layer 上训练 TopK sparse autoencoder，比较 vision tower 中两个 aspect 的同时激活和最终语言承诺。

主要贡献

提出 V-L asymmetry：vision tower 可能同时保留多个解释，语言生成端更早/更强地承诺到单一 aspect。

实验看点

摘要称 69 个可比样本中 72% 在 vision tower 同时激活两个 aspect feature pools；包含 12/12 forced-balanced stimuli。

局限与读法

样本是哲学/心理学式 ambiguous images，规模小；更适合作为机制诊断，不宜直接外推到普通图像 captioning。
