先说结论。通用视觉模型正在从静态表征转向 world model；ImageTime 给出了一种检查静态 image model 是否含有时序结构的方法。 把 image model 的评估从单图质量/图文对齐推进到“能否想象有时间顺序的视觉过程”。

核心问题

通用视觉模型正在从静态表征转向 world model；ImageTime 给出了一种检查静态 image model 是否含有时序结构的方法。

方法拆解

提出 ImageTime benchmark，用四个有序关键状态来测试图像生成模型是否能保持身份、物体、空间关系和因果顺序；输入可包含 action instruction 和可选初始参考图。

主要贡献

把 image model 的评估从单图质量/图文对齐推进到“能否想象有时间顺序的视觉过程”。

实验看点

摘要强调四关键帧协议比单图生成更有时序压力，同时避免完整视频评估中的 dense dynamics confound；并组织了 progressive capability hierarchy。

局限与读法

这是行为级 benchmark，不能直接说明模型内部学到了可迁移的动态表征；生成模型 prompt 能力也可能混入语言/模板偏置。
